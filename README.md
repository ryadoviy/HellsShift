# HellsShift

## Звіт розробника №1 — UI/UX, графіка, анімація та ігрова логіка - 'dnvwt'

### Реалізовано

- розроблено та вдосконалено візуальне оформлення гри;
- створено й відредаговано елементи інтерфейсу користувача (UI);
- опрацьовано дизайн і візуальний стиль ігрових елементів;
- створено та інтегровано графічні ресурси для гри;
- розроблено й налаштовано анімації персонажів, зокрема анімації руху та переміщення в різних напрямках;
- додано й опрацьовано анімаційні стани персонажів для забезпечення плавності та природності рухів;
- створено й інтегровано графічні ресурси привидів, зокрема спрайти для їхніх анімацій;
- значно доопрацьовано ігрову логіку та наявні скрипти;
- проведено масштабне редагування `GameManager`, зокрема логіки керування ігровим процесом;
- доопрацьовано `GameConfig` та параметри налаштування гри;
- вдосконалено систему пожежі `FireSystem`;
- реалізовано механіку поступового автоматичного збільшення рівня пожежі через певні проміжки часу;
- додано поетапне поширення вогню на кілька ділянок лабораторії зі зростанням рівня пожежі;
- доопрацьовано систему взаємодії з вогнем: реалізовано можливість використовувати воду для його гасіння;
- налаштовано взаємодію між системами пожежі, гравця та ігровим процесом;
- відредаговано й адаптовано сцени та скрипти для коректної роботи оновлених механік;
- проведено інтеграцію графічних, анімаційних та логічних компонентів у проєкт.

### Основні вдосконалені ігрові механіки

**1. Система автоматичного поширення пожежі**

- реалізовано поступове збільшення рівня пожежі з часом;
- налаштовано періодичне зростання показника вогню;
- забезпечено динамічну зміну рівня небезпеки під час гри.

**2. Механіка гасіння пожежі**

- доопрацьовано взаємодію гравця з вогнем;
- реалізовано використання води для зменшення рівня пожежі;
- інтегровано механіку гасіння з основною системою пожежі та логікою гри.

**3. Анімація та візуальна складова**

- створено й інтегровано анімації руху персонажів;
- опрацьовано рухи в різних напрямках;
- підготовлено графічні ресурси для анімацій привидів;
- вдосконалено візуальну складову та інтерфейс гри.

### Результат роботи

У результаті виконано значний обсяг роботи над візуальною та функціональною частинами HellsShift. Було вдосконалено інтерфейс і графічне оформлення, реалізовано анімації персонажів, інтегровано нові графічні ресурси та суттєво доопрацьовано наявні ігрові системи.

Окрему увагу приділено розвитку механік пожежі: тепер вогонь поступово збільшується з часом, а гравець має можливість впливати на його рівень за допомогою води.

Робота охоплювала як створення нових візуальних компонентів, так і редагування, вдосконалення та інтеграцію вже наявного коду проєкту.

## Звіт розробника №3 — `ryadoviy`

### Реалізовано

- створено базовий Godot 4 проєкт `HellsShift`;
- налаштовано Compatibility renderer;
- налаштовано розмір вікна `1280x720`;
- додано керування `WASD`, `E`, `Q` та `Esc`;
- створено головну сцену `main.tscn`;
- створено `GameManager` для запуску, паузи, таймера, очок і завершення гри;
- створено `GameConfig` та Normal-конфігурацію складності;
- створено систему пожежі `FireSystem`;
- додано рівень пожежі від `0` до `100`;
- додано сигнали `fire_changed` і `fire_maxed`;
- створено сцену лабораторії зі стінами та колізіями;
- створено базового гравця з рухом;
- створено `ModifierManager` як основу для секретних умов;
- додано HUD зі score, timer та fire level;
- додано стартове меню, паузу та екран результату;
- підготовлено інтеграційні точки для `Player`, `RecipeManager`, `Cauldron`, `Inventory` та `HUD`.

### Структура роботи

| Файл | Призначення |
|---|---|
| `project.godot` | Загальні налаштування та Input Map |
| `main.tscn` | Головна сцена гри |
| `game_manager.gd` | Стан гри, таймер, очки та інтеграція |
| `game_config.gd` | Параметри складності |
| `game_config_normal.tres` | Normal-конфігурація |
| `fire.tscn` | Сцена вогню |

| `laboratory.tscn` | Локація лабораторії |

| `modifier_manager.gd` | Резерв для секретних умов |
| `player.gd` | Базовий рух гравця |

### Запуск

1. Відкрити проєкт у Godot 4.
2. Запустити `main.tscn` або натиснути `F6`.
3. Натиснути `E`, щоб почати гру.

### Керування

- `WASD` — рух;
- `E` — старт гри / взаємодія;
- `Q` — скидання предмета, зарезервовано для інтеграції;
- `Esc` — пауза та продовження гри.

### Інтеграційні точки

- `FireSystem`: `increase()`, `decrease()`, `set_level()`, `fire_maxed`;
- `GameManager`: `start_game()`, `end_game()`, `add_score()`, `use_water()`;
- `ModifierManager`: реакція на ігрові події;
- `Laboratory`: сигнал `location_changed`;
- правильне завершення рецепту: `on_recipe_completed()`;
- неправильний інгредієнт: `on_ingredient_wrong()`.
